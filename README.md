> My first PCB, made possible by #solder, while at #juice 

A PCB in the shape of iron man's arc reactor that has LEDs controlled by a photoresistor

BOM:
- Photoresistor x 1 
- LED x 3
- 3V Battery x 1
- 47Ω resistor x 1
- 220Ω resistors x 3
- Push Button x 1
- 2N3904 transistor x 1
